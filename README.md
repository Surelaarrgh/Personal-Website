# Personal Website

Personal website of **Oluwashola Akanni** — software engineer & builder.

A fast, modern, single-page site built with plain HTML, CSS, and JavaScript.
No build step, no dependencies — just open it in a browser.

## Structure

```
Site/
├── index.html        # Page markup
├── styles.css        # Dark theme, layout, animations
├── script.js         # Scroll progress, reveal, nav, counters
└── assets/images/    # Hero + section imagery (from Unsplash, license-free)
```

## Run locally

Open `index.html` directly, or serve it (recommended, so relative paths resolve):

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000

## Sections

- **Hero** — intro with animated background and rotating tagline
- **About** — bio with animated stat counters
- **What I Do** — focus areas
- **Projects** — Pipeline Parity, Pipeline Order, Limina
- **Contact** — email + GitHub
